# Archivo Digital de Expedientes OVNI Desclasificados

## Descripción

Archivo Digital de Expedientes OVNI Desclasificados es una aplicación web desarrollada para la materia de Programación Web I. El sistema permite registrar y evaluar reportes relacionados con Fenómenos Aéreos No Identificados (FANI u OVNIs) mediante un formulario interactivo que calcula automáticamente un nivel de confiabilidad.

El proyecto está inspirado en los archivos y expedientes de fenómenos aéreos desclasificados, simulando una plataforma de análisis e investigación.

---

## Objetivos del Proyecto

* Aplicar conceptos de HTML5, CSS3 y JavaScript.
* Utilizar formularios para la captura de información.
* Implementar validaciones de datos.
* Manipular elementos del DOM dinámicamente.
* Generar clasificaciones automáticas según criterios definidos.
* Desarrollar una interfaz web responsiva y funcional.

---

## Funcionalidades

### Registro de Evidencias

El usuario puede registrar información sobre un supuesto avistamiento OVNI:

* Nombre del reporte.
* Lugar del avistamiento.
* Cantidad de testigos.
* Existencia de video.
* Existencia de imagen.
* Detección por radar.
* Explicación científica probable.
* Descripción del evento.

### Validaciones

* Verificación de campos obligatorios.
* Validación de archivos cuando se selecciona la opción de adjuntar evidencia visual.

### Clasificación Automática

El sistema calcula un puntaje de confiabilidad basado en los criterios definidos y clasifica el caso como:

* Evidencia Débil.
* Evidencia Moderada.
* Evidencia Fuerte.

### Resultados Dinámicos

Se muestran:

* Puntaje obtenido.
* Clasificación.
* Recomendación.
* Fecha y hora del análisis.
* Barra visual de confiabilidad.

### Historial de Expedientes

Cada evaluación realizada genera un expediente con:

* Código único (EXP-001, EXP-002, etc.).
* Nombre del reporte.
* Clasificación obtenida.
* Fecha y hora del análisis.
